# VPN для Windows

Здесь публикуются сборки приложения для Windows нашего VPN-сервиса. Подключение работает только
с подпиской, которую выдаёт администратор сервиса. Публикуются только проверенные версии.

## Установка

1. Скачайте установщик:
   [vpnapp_setup.exe](https://github.com/FriedCerebrum/vpn-client-desktop-releases/releases/latest/download/vpnapp_setup.exe).
   Все файлы версии лежат на странице [релизов](https://github.com/FriedCerebrum/vpn-client-desktop-releases/releases/latest),
   там же архив без установки (`vpnapp_<версия>_win-x64.zip`).
2. Запустите его. Права администратора не нужны: программа ставится в вашу папку пользователя.
3. Откройте ссылку на подписку, которую вам прислали (`vpnapp://import/…`): приложение добавит её само.
   Можно и вставить обычную ссылку подписки кнопкой «Добавить подписку».

Требуется 64-разрядная Windows 10 (версия 2004) или Windows 11.

### Предупреждение «Windows защитила ваш компьютер»

Установщик не подписан цифровой подписью (подпись платная), поэтому при первом запуске скачанного
из браузера файла Windows показывает синее окно SmartScreen. Это предупреждение, а не запрет:

1. нажмите **«Подробнее»**;
2. нажмите **«Выполнить в любом случае»**.

Так нужно один раз для каждого скачанного файла. Обновления, которые приложение скачивает само,
этого окна не вызывают. Целостность файла можно проверить по `SHA256SUMS` из релиза:
`Get-FileHash vpnapp_setup.exe -Algorithm SHA256` в PowerShell должна дать то же значение.
Антивирус может счесть ядро (Xray) подозрительным по эвристике: это ложное срабатывание, исходный код
открыт и приложен к релизу.

## Режимы работы

- **Системный прокси** (по умолчанию): работают браузеры и программы, которые используют системный
  прокси. Права администратора не нужны.
- **Весь трафик (TUN)**: перехватывает весь трафик компьютера. При включении Windows один раз спросит
  разрешение администратора (окно UAC), приложение перезапустится и подключится само.

Российские сайты и сервисы (банки, Госуслуги, Яндекс и другие) идут напрямую, остальное через VPN.

## Обновления

Раз в сутки приложение проверяет эту страницу и показывает кнопку «Установить». Обновление ставится
поверх, подписка и настройки сохраняются; VPN на время обновления отключается на полминуты.
Копия из zip сама обновиться не может: кнопка откроет эту страницу.

## Приватность

Что приложение собирает для диагностики подключения и что не собирает: [PRIVACY.md](PRIVACY.md).
Диагностика включается только с вашего согласия при первом запуске и выключается кнопкой «Диагностика».

## Удаление

«Параметры → Приложения → VPN → Удалить». Подписка и настройки лежат в `%LOCALAPPDATA%\VpnApp`;
при полном удалении эту папку можно удалить вручную.

## Исходный код и лицензия

Приложение основано на открытом проекте [v2rayN](https://github.com/2dust/v2rayN) и, как он,
распространяется по лицензии [GPL-3.0](LICENSE). Полный исходный код каждой версии приложен к её
релизу (`vpnapp-desktop-<версия>-src.tar.gz`).

Версия для Android живёт в отдельном репозитории,
[vpn-client-releases](https://github.com/FriedCerebrum/vpn-client-releases): потоки релизов независимы.
